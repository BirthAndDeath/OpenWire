# 软件建模模块项目计划

## 1. 建模目标

### 1.1 总体目标

为 OpenWire 建立完整的软件模型体系，覆盖领域模型、协议状态机、架构视图、安全威胁模型四大维度，使系统设计可验证、可沟通、可演进。

### 1.2 具体目标

| 维度 | 目标 | 受益方 |
| ------ | ------ | -------- |
| 领域模型 | 明确核心实体（ChatCore、P2pActor、ChatMessage 等）的属性、关系、生命周期 | 全体开发者 |
| 状态机 | 形式化定义协议状态转换，消除隐式状态和竞态条件 | P2P 协议开发者 |
| 架构视图 | 组件图、部署图、数据流图，降低新成员上手成本 | 新加入者、代码审查者 |
| 安全模型 | 信任边界、威胁树、密码学协议验证，支撑安全审计 | 安全审计者、密码学开发者 |

### 1.3 成功标准

- 所有核心状态机有明确的枚举定义和 `Transition`  trait
- 所有跨组件数据流有文档化的序列图
- 安全威胁模型覆盖 STRIDE 分类，已识别的威胁有缓解措施
- 模型与代码之间可自动或半自动保持同步（注释引用、测试断言）

#### 状态机实现示例

```rust
/// 连接生命周期状态机
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ConnectionState {
    /// 初始状态，无连接
    Disconnected,
    /// 拨号中（swarm.dial 已调用）
    Dialing,
    /// 连接已建立，等待 FriendOnline
    Connected,
    /// 连接关闭中
    Closing,
}

/// 状态转换
pub enum ConnectionEvent {
    Dial,
    ConnectionEstablished,
    FriendOnlineReceived,
    ConnectionClosed,
    Timeout,
}

impl StateMachine<ConnectionEvent> for ConnectionState {
    fn transition(self, event: ConnectionEvent) -> Result<Self, TransitionError> {
        match (self, event) {
            (Disconnected, Dial) => Ok(Dialing),
            (Dialing, ConnectionEstablished) => Ok(Connected),
            (Connected, ConnectionClosed) => Ok(Disconnected),
            (Dialing, Timeout) => Ok(Disconnected),
            (Connected, FriendOnlineReceived) => Ok(Connected), // 自环
            _ => Err(TransitionError::IllegalTransition),
        }
    }
}
```

## 附录 B：StateMachine trait 参考实现

```rust
/// 状态机转换错误
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct TransitionError {
    pub from: String,
    pub event: String,
    pub reason: &'static str,
}

/// 状态机 trait
pub trait StateMachine<E>: Sized + Clone {
    /// 执行状态转换
    fn transition(&self, event: E) -> Result<Self, TransitionError>;

    /// 检查转换是否合法（不实际转换）
    fn can_transition(&self, event: &E) -> bool {
        self.transition(event.clone()).is_ok()
    }

    /// 列出所有可能的后续状态
    fn valid_transitions(&self, events: &[E]) -> Vec<E>
    where
        E: Clone,
    {
        events
            .iter()
            .filter(|e| self.can_transition(e))
            .cloned()
            .collect()
    }
}
```

## 附录 C：状态机测试模板

```rust
#[cfg(test)]
mod tests {
    use super::*;

    /// 测试所有合法转换
    #[test]
    fn test_connection_legal_transitions() {
        let state = ConnectionState::Disconnected;
        assert_eq!(
            state.transition(ConnectionEvent::Dial).unwrap(),
            ConnectionState::Dialing
        );
    }

    /// 测试所有非法转换
    #[test]
    fn test_connection_illegal_transitions() {
        let state = ConnectionState::Disconnected;
        assert!(state.transition(ConnectionEvent::ConnectionClosed).is_err());
    }

    /// 测试状态机覆盖所有事件
    #[test]
    fn test_connection_enum_exhaustive() {
        let states = [
            ConnectionState::Disconnected,
            ConnectionState::Dialing,
            ConnectionState::Connected,
            ConnectionState::Closing,
        ];
        let events = [
            ConnectionEvent::Dial,
            ConnectionEvent::ConnectionEstablished,
            ConnectionEvent::FriendOnlineReceived,
            ConnectionEvent::ConnectionClosed,
            ConnectionEvent::Timeout,
        ];
        for state in &states {
            for event in &events {
                // 确保不会 panic
                let _ = state.transition(event.clone());
            }
        }
    }
}
```
