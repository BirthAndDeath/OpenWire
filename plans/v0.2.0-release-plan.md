## 风险应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| `curve25519-dalek` 升级导致依赖冲突 | 中 | 高 | 先运行 `cargo tree -i curve25519-dalek` 分析依赖树；必要时锁定版本号 |
| `hickory-proto` 无可用修复 | 高 | 中 | 记录到已知问题文档，等待上游发版；当前攻击面需 DNSSEC 响应 |
| npm 漏洞修复需 breaking change | 中 | 中 | 如 `@sveltejs/kit` 版本跳跃过大，推迟 npm 修复到 v0.2.1 |
| Clippy 修复引入新问题 | 低 | 低 | 每个 `--fix` 后运行 `cargo test` 回归 |
| 路由表缓存加载导致启动变慢 | 低 | 低 | 限制最大加载条目（100 条），先 `add_address` 不 dial |
